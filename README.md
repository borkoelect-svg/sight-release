# sight-release
It's very good music app for windows, arch and android! We got Yandex music, VK music and soon yt music and soundcloud
[README.txt](https://github.com/user-attachments/files/34870602/README.txt)
SIGHT 1.3.0
===========

Что внутри папки
----------------
1) Sight_1.3.0_x64-setup.exe  — установщик для Windows (64-bit)
2) Sight_1.3.0_android.apk    — приложение для Android

Windows
-------
Запустите Sight_1.3.0_x64-setup.exe и следуйте установщику.
При первом запуске Windows SmartScreen может показать предупреждение
(установщик не подписан платным сертификатом):
  «Подробнее» -> «Выполнить в любом случае».

Программа устанавливается только для текущего пользователя,
права администратора не нужны.

Android
-------
Скопируйте APK на телефон и откройте его. Разрешите установку
из этого источника, если система спросит.
Приложение подписано одним и тем же ключом, поэтому обновление
поверх предыдущей версии Sight проходит без удаления данных.

Что нового в 1.3.0
------------------
Плейлисты:
  • Исправлено главное: добавленный трек теперь действительно
    появляется в плейлисте и сохраняется после перезапуска
    (старая база обновляется автоматически при старте).
  • Новое окно «Добавить в плейлист»: список плейлистов со
    счётчиками треков, создание нового плейлиста сразу с треком.
  • Кнопка «+» у трека, в «Моей волне», в рекомендациях,
    в мини-плеере и в полноэкранном плеере.
  • Счётчики треков в списке плейлистов и в чипах.
  • Переименование плейлиста (карандаш рядом с названием).
  • Удаление отдельного трека из плейлиста (корзина).
  • Кнопка «Играть» и общая длительность в шапке плейлиста.
  • Защита от дублей: повторное добавление не создаёт копию.
  • Всплывающие уведомления о результате действия.
  • Поддержка обложек и альбомов у треков внутри плейлиста.
Всё перечисленное работает и в Windows-, и в Android-версии.

Важно про данные
----------------
Плейлисты, вход в Яндекс.Музыку и настройки теперь хранятся в
%APPDATA%\Sight (Windows) и во внутренней папке приложения
(Android), то есть не теряются при обновлении и перезапуске.

Требования
----------
Windows 10/11 x64, интернет для стриминга.
Android 7.0 (API 24) и выше.
